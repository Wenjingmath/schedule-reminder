# Schedule Reminder (日程提醒)

> 智能日程提取与提醒 Skill — 从截图、PDF、网页、手写照片等多种来源自动识别日程事件并设置提醒。

## 解决什么问题

日常生活和工作中，我们经常从各种渠道收到日程信息：会议邀请截图、课程表PDF、活动网页、手写便签、聊天消息等。手动将这些信息一条条录入日历既繁琐又容易遗漏。

**Schedule Reminder 解决了以下痛点：**

- 📸 **信息碎片化**：日程信息散落在截图、文档、网页等不同格式中，难以统一管理
- ⏱️ **手动录入耗时**：逐个输入事件标题、时间、地点效率低下
- 😅 **容易遗漏**：人工整理可能漏掉重要事件或输错时间
- 🔔 **提醒设置麻烦**：每个事件都要手动设置提醒，容易忘记

只需提供包含日程信息的文件或链接，即可自动提取事件并设置两级提醒（提前一天 + 当天），让日程管理变得轻松高效。

## 主要功能

### 1. 多源输入支持

支持从 7 种不同格式中提取日程信息：

| 输入类型 | 格式/扩展名 | 处理方式 | 典型场景 |
|---------|------------|---------|---------|
| **屏幕截图** | .png, .jpg, .jpeg, .webp | OCR文字识别 + 语义分析 | 会议邀请截图、活动海报、日程表截图 |
| **PDF文档** | .pdf | 文本提取 + 表格解析 | 会议议程、课程表、活动手册 |
| **网页链接** | URL | 网页抓取 + 内容提取 | 活动报名页、会议官网、日历页面 |
| **手写照片** | 图片格式 | 手写体OCR识别 | 手写便签、黑板笔记、手账照片 |
| **Anki卡片** | Anki导出 | 卡片内容解析 | 学习计划、复习日程 |
| **纯文本** | .txt, .md | 正则解析 | 日程列表、待办事项 |
| **Word文档** | .docx | 文本提取 | 会议通知、日程安排 |

### 2. 智能信息提取

自动识别并提取以下字段：

- **事件标题** — 事件的名称或主题
- **开始时间** — 事件开始的日期和时间
- **结束时间** — 事件结束的日期和时间（可选）
- **地点** — 事件发生的地点（可选）
- **摘要** — 事件的简要描述或备注（可选）
- **重复规则** — 重复事件的规则（如每周一，可选）

### 3. 两级提醒设置

根据提取的事件时间自动设置提醒：

| 提醒类型 | 默认时间 | 说明 |
|---------|---------|------|
| **提前一天提醒** | 事件前一天 09:00 | 提前规划当天行程 |
| **当天提醒** | 事件开始前 1 小时 | 确保不会错过即将开始的事件 |

提醒时间支持自定义配置。

### 4. 验证与确认

提取结果会先展示给用户确认，支持：
- 展示所有提取到的事件详情
- 用户可修正不准确的信息
- 确认后再正式设置提醒

## 安装方法

### 方式一：作为 TRAE Skill 安装

1. 下载或克隆本项目到本地
2. 打开 TRAE IDE，进入 **设置 → 技能**
3. 点击 **创建/导入** 按钮
4. 将 `schedule-reminder` 文件夹拖入导入区域
5. 确认安装即可使用

### 方式二：手动放置到项目目录

将 `schedule-reminder` 文件夹复制到项目的 `.trae/skills/` 目录下：

```
your-project/
├── .trae/
│   └── skills/
│       └── schedule-reminder/   ← 放在这里
├── src/
└── ...
```

### 方式三：本地开发使用

克隆项目后直接使用：

```bash
# 安装验证依赖
pip install pyyaml

# 验证技能结构
python quick_validate.py path/to/schedule-reminder

# 运行测试（需要额外依赖）
pip install PyPDF2 pillow reportlab
python schedule-reminder/scripts/test_extractor.py
```

## 使用方法

### 基本用法

向智能体提供包含日程信息的文件或链接，并描述你的需求：

```
帮我从这张会议截图中提取日程并设置提醒
```

```
把这个课程表PDF里的所有课程都加上提醒
```

```
https://example.com/conference/agenda 提取这个会议议程并提醒我
```

```
[手写字条照片] 帮我把这些待办事项设置成提醒
```

### 自定义提醒时间

在请求中明确说明提醒规则：

```
提前两天提醒我，当天提前2小时再提醒一次
```

```
当天提前30分钟提醒就行，不用提前一天
```

### 指定时区

```
用北京时间
```

```
转成纽约时间
```
